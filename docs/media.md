# Media subsystem

Откройте Media → Open video. Play запускает обычное воспроизведение, Pause / Resume работает с часами вывода, Stop завершает декодер. ASCII → Terminal запускает ASCII, первый кадр открывает Terminal. После этого можно свободно переключать страницы. Stop ASCII в Terminal останавливает воспроизведение. Цветовой режим задаётся на Media; Export ANSI сохраняет последний ASCII кадр.

Обычное видео выводит собственный WinForms VideoCanvas из RGB-кадров FFmpeg. Это устраняет зависимость вывода от native video window/GPU. Ограничение: 640×360 и 24 FPS, вписывание с чёрными полосами сохраняет пропорции. Аудио отдельно воспроизводит LibVLC. Точная синхронизация этих потоков пока не реализована; ASCII работает без аудио. Обработка кадров идёт на ПК, не на ESP32.

FFmpeg устанавливается через imageio-ffmpeg 0.6.0 в `.tools`, затем копируется рядом с приложением при сборке. Возможен собственный бинарник через MIKU_FFMPEG или `ffmpeg.exe` рядом с приложением. Внешний процесс запускается без shell, параметры передаются через ArgumentList; stdin отключён, stderr ограничен, отмена завершает process tree. При паузе выходной pipe создаёт обратное давление, поэтому кадры не накапливаются в памяти приложения.

Зависимости:

- [FFmpeg](https://ffmpeg.org/) — декодирование raw RGB. Лицензия конкретного распространяемого бинарника определяется его build configuration; установленный бинарник следует поставлять с соответствующими уведомлениями/условиями. В Git бинарник не включён.
- [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) — доставка FFmpeg для локальной разработки.
- [LibVLCSharp](https://github.com/videolan/libvlcsharp) 3.10.1 и VideoLAN.LibVLC.Windows 3.0.24 — аудиовоспроизведение. Лицензионные файлы native NuGet сохраняются в комплекте библиотек.

Перед публичной раздачей бинарного архива нужно включить лицензии конкретных FFmpeg/LibVLC builds и выполнить условия их распространения. Локальная автономная сборка подготовлена для разработки и демонстрации.

Тестовые видео с цветовой таблицей создаются локально через FFmpeg lavfi; сторонние изображения, музыка и ресурсы Hatsune Miku не используются.
