# История

## Control Center 0.4 / Firmware 0.3 — 2026-10-07

Настоящее хранилище FATFS во Flash ESP32-S3 с wear levelling, папками и UTF-8 именами. Передача текстовых и двоичных файлов блоками с CRC32, staging/journal при замене, версии snapshot, защитой путей, ограничениями ресурсов и отменой. Копирование — фоновая задача ESP32, продолжающаяся при закрытом Serial-клиенте. Добавлены shell-команды ls/cat/mkdir/rm/mv/cp/touch/write/df.

Windows Forms получил файловый менеджер, поиск в папке, редактор UTF-8 с Ctrl+S, сохранением BOM/переносов, предупреждением о несохранённых правках, защитой устаревшего сохранения и экспортом буфера на ПК. DeviceSession поддерживает асинхронные ответы, отмену и disconnect без потери синхронного ответа симулятора. Обычное обновление firmware сохраняет storage; первая инициализация выполняется отдельно с backup и проверкой существующего FAT.

Проверки: .NET, C++ recovery/timeout/copy, общий интеграционный сценарий для host и реальной платы, UI редактор и auto-connect. Физический power-loss при записи ещё не испытывался. Это файловая подсистема; интерпретатор сценариев остаётся планом развития.

## 0.2 — 2026-10-07

ESP32-S3 N16R8: рабочая ESP-IDF сборка, backup и прошивка, UART и PSRAM, аппаратные тесты. Расширены kernel API, состояния, журнал, диагностика памяти и конфигурация NVS. Control Center получил session слой, обновлённый Dashboard, System Monitor, экспорт, COM-порты и повторное подключение. Реализованы локальное видео, звук и ASCII/ANSI Video на ПК. Подготовлена автономная Windows x64 сборка.

## 0.1 — 2026-09-22

Первый вертикальный срез Simulator ↔ protocol ↔ Control Center, переносимое C++ ядро и ESP-IDF каркас. Аппаратного тестирования не было.
