# История

## 0.2 — 2026-10-07

ESP32-S3 N16R8: рабочая ESP-IDF сборка, backup и прошивка, UART и PSRAM, аппаратные тесты. Расширены kernel API, состояния, журнал, диагностика памяти и конфигурация NVS. Control Center получил session слой, обновлённый Dashboard, System Monitor, экспорт, COM-порты и повторное подключение. Реализованы локальное видео, звук и ASCII/ANSI Video на ПК. Подготовлена автономная Windows x64 сборка.

## 0.1 — 2026-09-22

Первый вертикальный срез Simulator ↔ protocol ↔ Control Center, переносимое C++ ядро и ESP-IDF каркас. Аппаратного тестирования не было.
