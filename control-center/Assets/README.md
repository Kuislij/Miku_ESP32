# Иллюстрации MikuOS

Оба PNG созданы для проекта 7 октября 2026 встроенным инструментом `image_gen` (режим built-in, прозрачный фон). Изображения из пользовательского референса не вырезались и не копировались. Логотипы, музыка и подписи чужих художников не включены. PNG встроены в .NET assembly и доступны без внешних файлов или интернета.

- `miku-hero.png` — иллюстрация для главного баннера.
- `miku-boot.png` — восемь кадров, сетка 4 × 2, последовательность слева направо, затем нижний ряд. При отрисовке используется nearest-neighbor.

## Промпт иллюстрации

Create an original polished anime illustration asset of Hatsune Miku for a desktop device dashboard. Transparent background, portrait composition, waist-up, centered with generous transparent margins so all hair and hands stay inside the image. Cheerful confident gentle smile, large turquoise eyes, very long flowing turquoise twin tails, charcoal headset with small pink accents, white sleeveless collared top and turquoise tie, modest outfit. She is making a small heart gesture with her hands near her chest. Clean refined anime line art, soft turquoise and pink shading, airy pastel palette, detailed but uncluttered. Facing slightly left toward dashboard content. Original drawing, no text, no logo, no watermark, no background scenery. Crisp professional illustration suitable displayed at about 300 pixels high on a pale aqua gradient card.

## Промпт заставки

A pixel art animation sprite sheet for a Hatsune Miku boot animation. One transparent PNG, precisely 4 columns by 2 rows of equal sized square cells, eight full body sprites, each centered in its own cell with generous empty transparent padding and no overlap. Each cell same scale and same baseline. Character is adorable chibi Miku with long turquoise twin tails, teal eyes, charcoal headphones with pink ear pieces, white shirt with teal tie, charcoal pleated skirt and boots. Retro 16-bit game pixel art: crisp hard pixel edges, limited palette, no smoothing, no text, no grid lines, no numbers, no background, no shadow beyond small pixel oval under feet. Reading left to right top then bottom, 8 distinct consecutive frames of a friendly wave and slight happy bouncing: standing, hand lifts, wave left, wave right, happy eyes closed bounce, wave left, wave right, hand lowered to standing. Same face proportions and costume throughout; movement of twin tails follows wave. All hair stays inside each cell. Clear separate sprites, front view, original animation artwork.
